# MDR

Ce dépôt contient le prototype **MDR — Mutualisation Des Ressources**.

Il s’agit d’un site web statique construit avec **Material for MkDocs** et publié automatiquement sur **GitHub Pages**.

L’objectif du projet est de rendre visibles et consultables différentes ressources utiles à la **recherche orientée par la conception**.
Le dispositif est volontairement simple sur le plan technique afin de rester facile à maintenir et à enrichir au fil du temps.
